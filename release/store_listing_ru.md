# MatchLab — store listing draft (RU)

## Название

MatchLab

## Короткое описание

Знакомства без бесконечных свайпов — небольшой выбор взаимно подходящих людей.

## Описание

MatchLab помогает знакомиться через совместимость, взаимные критерии и осознанный интерес.

Вместо бесконечной ленты приложение показывает небольшой набор подходящих кандидатов. До знакомства пользователь заполняет профиль, проходит анкету совместимости, указывает важные критерии партнёра и загружает фотографии.

Ключевые функции:
- персональный профиль совместимости;
- взаимные обязательные критерии;
- объяснение совместимости по основным категориям;
- «Интересен человек» и «Пока пропустить» вместо свайпов;
- чат только после взаимного интереса;
- блокировка и жалобы;
- управление статусом знакомств;
- режим предварительного набора аудитории.

MatchLab предназначен только для пользователей 18+.

## Категория

Основная: знакомства / social discovery.

## Возраст

18+.

## Поддержка

Support URL: требуется перед публикацией.

## Юридические ссылки

Privacy Policy URL: требуется перед публикацией.

Terms of Use URL: требуется перед публикацией.

## Аккаунт для ревью

Требуется перед публикацией после подключения production HTTP runtime и мобильного клиента.

## Платные функции

Архитектура поддерживает:
- FREE;
- PREMIUM;
- PREMIUM_PLUS;
- разовый глубокий отчёт совместимости.

Платные функции не должны блокировать базовую механику знакомства в первом MVP.

## Что ещё требуется для финального listing package

- иконка приложения;
- скриншоты iOS и Android из фактических release builds;
- support URL;
- Privacy Policy URL;
- Terms URL;
- инструкции для reviewer;
- подтверждённый account deletion flow;
- фактические privacy/data declarations для production-клиентов.
